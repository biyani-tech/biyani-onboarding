## Afternoon: your first pull request

Your first change is to **this website**. It's low-risk, and it teaches you the whole Git and GitHub flow in one go.

1. Clone this site's repository.
2. Create a branch: `git switch -c glossary-<the-word>`
3. Open `docs/handbook/glossary.md` and add one word you heard today and had to look up, with a one-line explanation in your own words.
4. Run `npm install` then `npm run dev` and check how it reads on the page.
5. Commit, push, and open a pull request.
6. Answer any review comments; your trainer merges it.

Every word you add makes the next batch's first week easier. This site is public, so keep people's names out of your branch name, commit message and the page itself.

::: tip Laptop not ready? You can still do this
Click **Suggest a change to this page** at the bottom of any page and make the same edit on GitHub in your browser. It's the same pull request, with nothing to install.
:::

New to Git? Read [Git and GitHub](/learn/git-github) first.
