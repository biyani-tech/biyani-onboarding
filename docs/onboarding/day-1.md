## Midday: set up your laptop

- [ ] Work through [Set up your laptop](/onboarding/setup) with the trainer
- [ ] Post a screenshot of `docker run hello-world` working in the group

## Afternoon: your first pull request

Your first change is to **this website**. It's low-risk, and it teaches you the whole Git and GitHub flow in one go.

1. Clone this site's repository.
2. Create a branch: `git switch -c add-<your-name>`
3. Open `docs/handbook/team.md` and add yourself to the interns table.
4. Run `npm install` then `npm run dev` and check your row on the page.
5. Commit, push, and open a pull request.
6. Answer any review comments; your trainer merges it.

New to Git? Read [Git and GitHub](/learn/git-github) first.
