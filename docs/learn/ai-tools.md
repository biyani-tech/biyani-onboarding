# AI coding tools compared

You'll use one main tool, but you should know the others, because the field changes fast and the team may switch. Prices and limits change often; check each tool's site before relying on a number.

| Tool | Made by | Where you use it | Free option | Good at |
| --- | --- | --- | --- | --- |
| **Google Antigravity** (our main tool) | Google | Desktop app with an Agent Manager, plus an IDE and a CLI | Free individual tier with weekly agent limits | Multi-step agent work: plans, builds, checks in a browser |
| **Claude Code** | Anthropic | Terminal, VS Code and JetBrains extensions, desktop | None; needs a paid Claude plan or API billing | Long, careful agentic tasks across a whole codebase |
| **OpenAI Codex** | OpenAI | CLI, VS Code extension, ChatGPT app and web | Included in ChatGPT Free, with small limits | Well-scoped tasks; cloud tasks on paid plans |
| **GitHub Copilot** | GitHub (Microsoft) | VS Code, Visual Studio, JetBrains, github.com | Copilot Free: up to 2,000 completions a month plus limited chat and agent use | Inline suggestions, chat in VS Code, PR reviews on GitHub |
| **Cursor** | Anysphere | Its own editor, based on VS Code | Hobby tier | An editor built around AI from the start |

## What's the same everywhere

The skills on [AI fundamentals](/learn/ai-fundamentals) work in every tool: clear prompts, small steps, plan first, read every diff, keep rules in `AGENTS.md`. Learn those, and switching tools takes an afternoon.

## What differs

- **Where it lives:** inside your editor, in the terminal, or as its own app.
- **How much it does alone:** autocomplete only, or a full agent that runs commands.
- **Limits and cost:** free tiers run out; paid plans differ a lot.
- **Model choice:** some tools let you pick the model, others choose for you.
