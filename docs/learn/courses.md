# Free courses

Short, free and chosen for what you'll actually do here. Times marked approx. are estimates.

## If you only do one

**[Claude Code: A Highly Agentic Coding Assistant](https://www.deeplearning.ai/short-courses/claude-code-a-highly-agentic-coding-assistant/)** (DeepLearning.AI with Anthropic, about 1 hour 50 minutes). It's about one tool, but it teaches what every agent needs: giving clear context, managing the context window, planning before building, and checking the work. Everything carries over to Antigravity and Codex.
