# How we communicate

We use **WhatsApp** for day-to-day talk and **GitHub** for anything about code.

## WhatsApp

**Group:** the team or batch group your trainer adds you to.

### Daily stand-up, by 10:30

Post one message in this format:

```
Done: set up Docker, read the spec
Doing: entry form for lane 2
Blocked: EF Core can't connect to the database (error in thread)
```

### Asking for help

- Stuck for **30 minutes**? Ask. Waiting longer wastes your time and ours.
- Say **what you tried**, and paste the **full error as text**, not a photo of your screen.
- Use the group, not private messages, so everyone learns from the answer.
- Reply in the same thread (swipe to reply) to keep conversations together.

### Please don't

- Send real student, staff or client data, passwords or connection strings. Not even in a screenshot.
- Use voice notes for technical problems; text can be searched and copied.
- Expect replies outside working hours unless something is on fire.

## GitHub

- Discuss code **on the pull request**, next to the lines in question.
- Link the PR in WhatsApp when you need a review: "PR ready for review: [link]"
- Use issues for anything that's left over or broken.

## Working hours

Your trainer confirms office hours, the lunch break and how to report leave on Day 1, and they're pinned in the team group. They're not on this site because it's public.
