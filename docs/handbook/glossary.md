# Glossary

Words you'll hear in your first week. Add any you had to look up.

## Our world

| Word | Means |
| --- | --- |
| ERP | Enterprise resource planning: software that runs an organisation's daily admin (admissions, fees, exams, payroll) |
| CMS | In our team, College Management System, our ERP for colleges |
| Galaxy | Our main college and school ERP product |
| NAAC | National Assessment and Accreditation Council: grades Indian colleges and universities |
| NBA | National Board of Accreditation: accredits engineering and technical programmes |
| DPDP | India's Digital Personal Data Protection Act and Rules; stricter for anyone under 18 |
| Division | A section of students in one year of a programme, e.g. "SE CE A" |
| Batch | A smaller group inside a division for practicals, e.g. "A1" |
| SE / TE / BE | Second, third and final year of an engineering degree |
| Campus edition | Our product installed on a college's own server instead of the cloud |
| Tenant | One customer institution on our shared cloud platform |

## Tech

| Word | Means |
| --- | --- |
| LTS | Long-term support: a version that gets security fixes for years |
| .NET 10 | Microsoft's C# platform; our backend, supported to Nov 2028 |
| EF Core | Entity Framework Core: talks to the database from C# |
| PostgreSQL | Our database |
| Docker | Runs software in containers so it works the same everywhere |
| CI | Continuous integration: automated build and test on every pull request |
| OpenAPI | A file describing an API's endpoints, so front end and back end agree |
| Multi-tenant | One system serving many customers, keeping their data apart |
| RLS | Row-Level Security: PostgreSQL feature that hides other tenants' rows |

## AI

| Word | Means |
| --- | --- |
| LLM | Large language model: the AI behind coding tools |
| Token | The chunk of text a model reads and writes; limits and prices are counted in tokens |
| Context window | Everything the model can see at once in a session |
| Prompt | Your instruction to the model |
| Agent | An AI tool that edits files and runs commands to finish a task |
| Plan mode | The agent plans without changing anything until you approve |
| Hallucination | A confident answer that's wrong |
| AGENTS.md | A file of project rules that AI tools read |
