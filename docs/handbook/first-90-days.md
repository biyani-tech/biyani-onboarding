# Your first 90 days

A rough guide, not a contract. Your trainer and buddy will adjust it to you.

## Days 1–30: learn by doing

- [ ] Finish onboarding, the 3-day AI sprint and the timetable challenge
- [ ] Get your first **real** pull request merged in a live product: a small bug fix or a report change, paired with your buddy
- [ ] Review at least three teammates' pull requests
- [ ] Learn one product well enough to demo it to a new user

**You're on track if** you can pick up a small, clearly written ticket and finish it with occasional help.

## Days 31–60: take on more

- [ ] Complete five or more tickets, at least one touching the database
- [ ] Write tests for something that had none
- [ ] Sit in on a customer support call or a client demo
- [ ] Present one thing you learned to the team (15 minutes)

**You're on track if** you can break a medium task into steps and get an agent to build it safely.

## Days 61–90: own something

- [ ] Own one small module or feature end to end: build, test, document, support
- [ ] Help run the next batch's AI sprint or timetable challenge
- [ ] Improve this onboarding site with what you wish you'd known

**You're on track if** teammates come to you with questions about your area.
